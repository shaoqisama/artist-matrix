# 🟢 Alien: Earth → Artist Matrix TUI Visual Guide

### 🎨 Color Palette

* **Base:** Black / Deep navy backgrounds
* **Accents:** Acid green (#00FF7F), Electric blue (#1E90FF), Rust brown (#8B4513), Concrete gray (#696969)
* **Usage:**

  * Green → warnings, active text, cursor blink
  * Blue → neutral/system info
  * Rust/gray → frame borders, separators

### 🔤 Typography

* **Titles:** Wide-spaced futuristic sans-serif (ALIEN-style caps)
* **Body/Interface:** Monospaced retro terminal font (green-on-black, ASCII feel)
* **Style:** Minimal glow effects, blinking cursor for “alive” terminal vibe

### 📐 Layout

* **Centered key art:** ASCII silhouettes (xenomorph, planet, egg) framed by text menus
* **Modes:**

  * **Ship/claustrophobic:** Dense grid or panel-like menus
  * **Earth/open:** Wider spacing, map-like arrangement

### 🎞 Motion

* **Transitions:**

  * Slow typing reveals
  * Occasional glitch/static bursts
  * Sudden rapid scrolls for “jump-scare” text moments

### 🖼 Iconography

* Weyland-Yutani `[WY]` tag, hazard stripes (`██░░██`), blinking radar blips (`* . *`)
* ASCII chestburster storm (swirls of `~` or `@`)
* Minimalist silhouettes (alien head `((<:>)`)

### 🌌 Mood/Atmosphere

* **Retro-futurist dystopia**: analog, glitchy, used-up tech
* **Tone:** Ominous, suspenseful, “safer in space” irony
* **Goal for TUI:** Interface feels **alive but unstable**—as if it could fail at any moment

👉 Think: *dark console with eerie neon highlights, slow text bleed, ASCII creatures emerging from shadows*.
